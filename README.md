# API REST - Catálogo de Jogos

Projeto prático desenvolvido para as avaliações AV1 e AV2 da disciplina de Desenvolvimento de Websites (UNASP).

## Tecnologias
* Node.js
* Express
* JavaScript

## Rotas Principais
* `GET /jogos` - Listar todos os jogos
* `GET /jogos/:id` - Buscar jogo por ID
* `POST /jogos` - Cadastrar jogo
* `PUT /jogos/:id` - Atualizar jogo
* `DELETE /jogos/:id` - Deletar jogo
